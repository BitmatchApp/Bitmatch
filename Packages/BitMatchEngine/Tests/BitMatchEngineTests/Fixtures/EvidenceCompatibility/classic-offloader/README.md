# Independent Offloader classic MHL fixture

`media/offloader.mhl` was generated by the MIT-licensed
[Offloader](https://github.com/owenpkent/offloader) writer at commit
`e01a0eb034fd0056ae4a3385b187c70ba96d2a49`. The writer's license is retained
in this directory. The fixture contains original synthetic data, including an
empty file and a non-ASCII filename.

The writer's `write_mhl` function was called directly with a synthetic job and
destination entries. The two MD5 values were calculated with Python's
`hashlib`; all job and file dates were fixed to 2026-01-01 UTC. The writer's
username and hostname providers were replaced with the literal `synthetic`
before writing, and the job was named `Synthetic fixture`. The output XML was
not edited afterward. The writer was invoked under Python 3.9 even though its
project declares Python 3.10 or newer. The writer's own verifier and an
external schema validator have not yet been run on this fixture.
