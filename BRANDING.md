# BitMatch name and icon

BitMatch's code is MIT licensed. Fork it, improve it, and ship something of your own. The BitMatch name and icon identify the official app; the code license does not give a fork permission to present itself as an official BitMatch release or imply my endorsement.

If you distribute a fork, use your own app name, icon, bundle identifier, and store listing. You can say it is based on BitMatch, as long as that is clear and you don't make people think it comes from this project.

This is about product identity, not a restriction on the MIT code license. If you want to collaborate on an official release or use the BitMatch branding, [get in touch](https://github.com/BitmatchApp/Bitmatch/discussions).
