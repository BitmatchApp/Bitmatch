# Synthetic 4K report preview memory probe

October 19 overnight, 2026. Mac host scratch only, using the real Standard
copy/readback pipeline, `ReportThumbnailService` and PDF renderer. No physical
card/backup, MHL handoff or durable History workflow is claimed by this probe.

One original, locally generated 3840×2160 H.264 asset contains two frames of a
four-colour quadrant pattern. It was materialized at 20 distinct source paths,
then 200 after the smaller run stayed comfortably below the guard. This tests
repeated-path decoder/report handling, not unique clip content, codec diversity,
long-GOP footage, large encoded files or the cause of issue #23.

| Final run | Tests passed / skipped | Initial / overall peak / after settling | Decoder peak | PDF peak | Collection |
| --- | --- | --- | --- | --- | --- |
| Normal, opt-in disabled | 2 / 1 | Not run | Not run | Not run | Not run |
| 20 clips | 3 / 0 | 45 / 103 / 83 MiB | 79 MiB | 82 MiB | 20/20 in 0.548 s |
| 200 clips | 3 / 0 | 45 / 103 / 99 MiB | 82 MiB | 97 MiB | 200/200 in 4.532 s |

All runs had zero failures and zero xcresult runtime warnings. The opt-in runs
include the two small guard tests plus one real probe. Final test times were
0.004 s (normal), 4.058 s (20) and 13.240 s (200). Sampling used the process's
`phys_footprint` every 10 ms, with separate fixture, copy/verify, decoder, PDF,
post-check and two-second settling phases. Brief peaks between samples can be
missed. The largest peak occurred while constructing the 4K fixture. Neither
real run reached the 1,024 MiB guard; small mocked tests check threshold-triggered
worker cancellation and refusal to treat a missing sample as zero memory.

The guard cancels the owned worker and pipeline and prevents subsequent phases.
Owned fixture/hash tasks are joined before returning. It requests native decoder
cancellation but cannot forcibly interrupt AVFoundation, synchronous PDF drawing
or filesystem calls. Failed/guarded fixtures and generated bytes are retained.
This is a bounded probe, not an out-of-memory survival guarantee or a leak proof.

Production limits stayed unchanged: 200 previews, a 30-second collection budget
and a two-second per-clip timeout. Every actual pipeline result was independently
hash-verified, and source/destination SHA-256 snapshots matched afterward. Any
engine status marker encountered by the hash helper must be valid; this host
probe does not establish that a marker is required or present on every filesystem.
Every collected JPEG was at most 64 KiB, exactly 256×144, and retained the
expected red/green quadrant differences. PDF resources passed the same pixel
check. Independent Poppler inspection counted 20 and 200 JPEG **placements**;
Quartz reused the identical synthetic image resources. Captions retained every
source clip. All 3/15 PDF pages were rendered privately; this is headless report
evidence, not a signed-app or device walkthrough.

The initial renders exposed a separate pagination rough edge: a last page with
only Job ID/version. These memory results precede its separate layout work.

Run only with the Mac host reserved:

```sh
TEST_RUNNER_BITMATCH_HIGH_RES_PREVIEW_MEMORY=1 \
TEST_RUNNER_BITMATCH_HIGH_RES_PREVIEW_ARTIFACTS=/private/tmp/bitmatch-preview-evidence \
xcodebuild -project BitMatch.xcodeproj -scheme BitMatch \
  -destination 'platform=macOS' -jobs 4 -parallel-testing-enabled NO \
  -only-testing:BitMatchTests/ReportPreviewMemoryTests test
```

The default is 20 clips. `TEST_RUNNER_BITMATCH_HIGH_RES_PREVIEW_CLIPS` accepts
20–200; increase only after the smaller measured run is safe. Exported probe
PDFs contain generated local paths, so keep raw artifacts private.
